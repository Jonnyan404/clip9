# clip9 for Android

把 clip9 装进手机：**服务端跑在手机里**（Rust 编成 `.so`，由前台服务托管），界面用内嵌
WebView 显示。所以手机既能自己开一个 clip9 给别人连，也能当客户端连别人的服务器。

## 装

到 [Releases](https://github.com/Jonnyan404/clip9/releases) 下载 `clip9-android-v<版本>.apk`
装上即可 —— 一个包里含 `arm64-v8a` / `armeabi-v7a` / `x86_64` 三个 ABI，不用挑。
想要小一点的包，可以下带 `-<abi>` 后缀的那三个之一。

系统要求：**Android 7.0（API 24）**及以上（那一档是由系统 WebView 的版本决定的）。

## 用

**当服务端**（同一个局域网里别的设备来连你）：

1. 打开 App →「配置」页设监听端口、访问密码等 → 点**启动服务**；
2. 别的设备访问 `http://手机局域网IP:9501`（局域网地址与二维码在「连接」页顶部）；
3. ⚠️ 想让它在后台活下来，把 App 加进**电池优化白名单** ——「其它」页里那一行会直接弹出
   系统的请求框（有些 ROM 会把它挡住，那就退到系统的白名单列表页，自己找 clip9）。
   服务端运行时会有一条常驻通知：那是 Android 对前台服务的硬要求，它表示「别的设备能连过来」。

**当客户端**（用手机看别人的 clip9）：

「连接」页 → 添加服务器（**可以存多台**，各带自己的房间与密码）→ 点进去直接用内嵌界面打开那台。
打开前它会先用保存的密码换一张会话令牌，所以在网页里**不用再输一遍密码**。

## 分享进来的文本

在别的应用里「分享 → clip9」，App 会起来并把那段文本发到当前房间。

⚠️ 只支持**文本**。图片与文件那条路在 WebView 里做不通（页面拿不到文件路径），**还没做**。
