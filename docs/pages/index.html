你自己的剪贴板服务器

手机复制，电脑粘贴。文本、图片、文件在任意设备之间实时互传，而数据一直留在你自己的机器上。

docker run -d --name clip9 --init -p 9501:9501 ghcr.io/jonnyan404/clip9:latest 复制

localhost:9501

复制即同步

一端粘贴，另一端立刻收到 —— 中间没有第三方服务器，也没有账号。

  • WebSocket 双向广播，实时推送
  • 历史走 HTTP 分页拉取，不推全量
  • 桌面端可静默双向同步系统剪贴板

手机、电脑、路由器都能当服务端

同一份代码，六种落地方式。路由器上 16 MB flash 也跑得动。

  • Docker 一行命令起服务
  • OpenWrt 带 LuCI 插件，装完在路由器后台配置
  • Android 一键开服，不用电脑

一条内容，换个方式看

内置动作库：Markdown 渲染、JSON 美化、编解码、汉字注音、日期计算…… 也能把几个动作串成流水线。

  • 时间流 / 速览 / 便签 / 看板多种模式
  • 定时自动化：按 cron 把渲染好的文本投进房间
  • 分享链接：可限次数、可带密码

装在哪都行

默认监听 9501，装完打开浏览器就是界面。
