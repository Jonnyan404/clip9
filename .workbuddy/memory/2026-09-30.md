## clip9 服务端 API 的 OpenAPI v3 spec（新建 `docs/openapi/`）

**做了什么**：读 `rust/crates/server/src/lib.rs::router` 的路由表 + 各 handler，产出
`docs/openapi/clip9.openapi.yaml`（OpenAPI **3.1**，31 paths / 37 operations / 51 schemas /
187 个具名 example），外加 `check-openapi.py`（结构 + example 双校验）与 `README.md`
（含「与 `docs/api.md` 的偏离」对照表）。

**校验结果**：`openapi-spec-validator` 过；`check-openapi.py` 报
`all 187 named examples conform to their schemas`。路由表也**程序化对过**代码：
代码 32 条 route 与 spec 的 31 个 path 一致，方法集无差异，只差
`/tasks/{id}/{action}`（catch-all 405，OpenAPI 表达不了，已在描述里说明）。

**读代码读出来的、与 `docs/api.md` 不一致的几处**（spec 一律以**代码**为准，标 `NOTE (code)`）：

- `content_entry()` 里**文件条目的 `type` 是媒体种类**（image/video/document/…），
  **不是** `"file"`；只有 WS `ReceiveEntry`（`ReceiveHolder` 序列化）才是 `"file"`。
  → 所以 `ContentEntry` 与 `ReceiveEntry` 是**两套** schema，不能共用。
- `GET /content/latest` 的 JSON 是**精简形状**（text: type/content/id/timestamp/column），
  **不是** `GET /content` 那个富投影（无 room/senderIP/senderDevice/cache）。
- `/content/latest` 不传 room = `default`；跨房间取最新要显式 `?all=1`（Go 那边是隐式的）。
- `senderDevice` 是**自由 string map**（`type`/`os`/`browser`/`name`，`type` 是小写
  `desktop`/`smartphone`/`tablet`，定时任务那条是 `{name,type:"Automation"}`），
  **不是** WS `connect` 事件那个严格的 `DeviceMeta`（后者必有 `id`/`device`）。踩过一次：
  最初把 senderDevice 指向 `DeviceMeta`，example 校验立刻红了。
- 上传的响应体只有 `{url,id,type}`（`api.md` 里写的 `uuid`/`name`/`size`/`expire` 是旧的）。
- `/revoke/*` 在 Rust 上**只认 POST**（Go 那边任何方法都会真删）。
- `/upload` 在 `Content-Type == "text/plain"`（**全等**）时变成分片上传的初始化。
- `POST /tasks/preview` 的参考时刻字段叫 `referenceAt2`，而已保存任务的 dry run 叫
  `scheduledAt`（`referenceAt` 两边都是 Unix 秒）。
- `/content/{id}/column` 的鉴权错码是 `room_auth_required`，读接口是 `room_forbidden`。
- `upload` 响应里的 `type` 是媒体种类，不是 `"file"`。

**踩到的工具坑（这次新学到的）**：

1. **`openapi-spec-validator` 不校验 example**。它只证明文档结构合法，会**原样放过**
   与 schema 矛盾的 example —— 而 example 正是最容易被信任、也最容易写错的部分。
   → 自己补一段 `jsonschema` 校验（就是 `check-openapi.py` 干的事）。
2. **手写 spec 时 `$ref` 是"裸指针"**（`#/components/schemas/X`），`jsonschema`
   直接拿去校验会报 `PointerToNowhere`：**嵌套 `$ref` 不会被解析**。
   → 最省事的做法是**先把 ref 全量内联**（递归 expand + 环检测），再交给 jsonschema。
3. **OpenAPI 里 path 参数必须 `required: true`** —— `/file/{uuid}` 与 `/file/{uuid}/{name}`
   是两条路径，不能在第一条里塞一个"可选"的 `{name}`。校验器直接拒。
4. YAML 里**值中带 `: ` 必须加引号**：`message: Unauthorized: Missing token` 会被当成嵌套 mapping
   （报 `mapping values are not allowed here`）。反引号里的 `` `valid: true` `` 同样中招。
   这次一共引了 6 处。
5. 环境里**没有 YAML 库**（managed python / 系统 python / node workspace 都没有），
   也没有 node_modules。装法：managed venv
   `/Users/jonny/.workbuddy/binaries/python/envs/default/bin/pip install pyyaml openapi-spec-validator`
   （只涨了几个目录，**没有**触发沙箱规则表被撑爆那条老坑）。
