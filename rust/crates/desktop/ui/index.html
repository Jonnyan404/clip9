服务端与房间

↑ 把本机剪贴板发到这个房间，↓ 把这个房间的内容收进本机剪贴板（全局只能一个）。

方向与内容

↑ 发到房间（可多房间同时开）
✓文本默认开
✓文件（图片走这条）上限还不知道
富文本 / HTML本版按文本处理
↓ 收进剪贴板（全局只能一个房间）
✓文本
✓文件（含图片）
—在左侧栏用 ↓ 选

装完两个方向都关着。连上时服务端会重放历史 ——历史只进列表，不写剪贴板。

监听与去重

剪贴板是轮询读的（系统没有「剪贴板变了」这个通知）。间隔 = 多快同步过去 / 空转多少。

改完点「保存」才生效 —— 它会重启监听线程。

什么时候在读你的剪贴板

有房间开着↑才读；一个都没开就把轮询线程停掉。
↓ 与此无关，连接照常—— 设备、延迟、别人发来的内容都不受影响。

去重

同一份内容连着出现不会发两遍（按类型记指纹）。没有开关。

窗口与托盘

开机自动启动

勾的是系统里的真相（启动项在不在），不是我们「想要」的值。装完默认不开。

托盘

菜单：打开主窗口 / 开机自动启动 / 切换房间 / 退出。
关掉窗口只是藏起来—— 同步照常跑，要退出得走托盘。

快捷键

全局快捷键关掉就不占这个组合键

按一下显示 / 隐藏主窗口 —— 再按一下换回来。

通知

剪贴板上那两件事发生时你多半不在这个窗口里，所以走系统通知。

剪贴板的系统通知
✓本机剪贴板没发出去时通知我成功不通知
✓房间的内容写进本机剪贴板时通知我

第一条只在没发出去时响（「已发送」是噪音）；第二条每次写成都响（剪贴板被改你看不见）。
